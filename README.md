# Stock Finder - React TypeScript Project

A modern, responsive stock market analysis application built with React 19, TypeScript, Tanstack and HighCharts. Search and analyze securities with real-time data, interactive charts, and comprehensive company profiles.

## 🚀 Live Demo

**[View Live Application](https://stockfinder-omega.vercel.app/)**

## ✨ Features

- **Real-time Stock Search**: Search securities by name or symbol with instant results

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Material-UI
- **State Management**: TanStack Query (React Query)
- **Routing**: React Router v6
- **Charts**: Highcharts
- **Build Tool**: Vite
- **Deployment**: Vercel
- **API**: [Financial Modeling Prep](https://financialmodelingprep.com/) for providing the financial data API
